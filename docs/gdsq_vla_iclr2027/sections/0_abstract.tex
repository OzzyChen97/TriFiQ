\begin{abstract}
Post-training quantization (PTQ) usually calibrates a network on fixed teacher data and evaluates local reconstruction error. This formulation is incomplete for closed-loop vision-language-action (VLA) policies: quantization perturbs actions, altered actions change future observations, and the compressed policy therefore changes the input and activation-range distributions on which its own numerical fidelity depends. We call this the \emph{full-context gap}. \method addresses three coupled forms of missing context: temporal control context through physical-sequence divergence, whole-policy context through an exact-budget precision audit that may abstain, and deployment context through per-forward channelwise A8 scaling. Local layer interventions only propose masks; complete-policy evidence under teacher- and candidate-induced observations decides whether to accept a proposal or retain the initializer. On 50 RoboCasa365 tasks and 2,500 GR00T N1.5 episodes per configuration, \method achieves \textbf{54.0\%} success at 2.22$\times$ static compression, compared with 30.4\% for size-matched QuantVLA W4A8 (Holm-adjusted $p<10^{-4}$) and 55.1\% for FP16; the current test does not establish equivalence to FP16. The audit abstains on GR00T and retains its initializer. In a paired 500-episode intervention, a calibrated frozen A8 table obtains 0/500 successes, whereas input-conditioned A8 obtains 269/500. On $\pi_{0.5}$, the compressed policy obtains 27.7\% success at 2.702$\times$ static compression. These results expose fixed-distribution calibration as a concrete failure mode and motivate policy-level, abstaining evaluation for VLA compression.
\end{abstract}
