\begin{abstract}
Post-training quantization (PTQ) can reduce the static storage of vision-language-action (VLA) policies, yet errors that appear harmless at one layer can accumulate across action chunks and complete policy contexts. We present \method---\emph{Dynamic-Range and Prefix-Accumulated Control-aware Quantization}---a training-free mixed-precision framework that evaluates precision decisions in the complete policy. Its control metric, \dpac, measures local action error, prefix accumulation, composed SE(3) pose drift, chunk-boundary discontinuity, and gripper-event timing, with a tail-risk penalty. Full-Context Precision Protection then searches native-FP16/group-64-W4 masks under an exact byte budget and accepts a change only after whole-network, cross-context adjudication. At deployment, Hessian-aware W4 weights are paired with \dyrange, which recomputes per-channel A8 scales on every forward pass; no task routing or runtime correction is used. On 50 RoboCasa365 tasks and 2,500 paired GR00T N1.5 episodes per configuration, \method achieves \textbf{54.0\%} success at 2.22$\times$ static component compression. This is 23.6 points above QuantVLA W4A8 (Holm-adjusted $p<10^{-4}$), while the difference from the 55.1\% FP16 teacher is not significant ($p=0.2929$). A separate $\pi_{0.5}$ study reaches 2.702$\times$ compression, but is reported only as a compression anchor because its 100-episode screen does not establish a success-rate gain.
\end{abstract}
