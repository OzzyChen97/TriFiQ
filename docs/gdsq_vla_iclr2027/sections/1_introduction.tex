\section{Introduction}
\label{sec:introduction}

Vision-language-action (VLA) models connect visual perception and language-conditioned reasoning to continuous robot control~\cite{brohan2023rt2,octo2024,kim2024openvla,black2024pi0,intelligence2025pi05,bjorck2025groot}. Their large multimodal backbones and iterative action generators make static storage and memory bandwidth important deployment constraints. Post-training quantization (PTQ) is attractive because it reduces numerical precision without retraining the policy~\cite{xiao2023smoothquant,lin2024duquant}.

Most PTQ formulations treat calibration data as exogenous: collect a fixed teacher buffer, minimize tensor error on that buffer, and deploy the resulting network. Closed-loop control breaks this assumption. Quantization changes an action; that action changes the next state and observation; the new input changes activation ranges and subsequent quantization error. The object being compressed is therefore not merely a network evaluated on fixed data, but a policy operating on the state distribution induced by its own quantized actions. We call the missing dependence between numerical error and policy-induced data the \emph{full-context gap}.

The full-context gap has three coupled axes. \emph{Temporal control context} is lost when local MSE ignores coherent prefix accumulation, nonlinear SE(3) composition, replan stitching, gripper timing, and rare catastrophic sequences. \emph{Whole-policy precision context} is lost when a layer score decides precision without testing the complete mixed-precision network in which that layer operates. \emph{Deployment-distribution context} is lost when a frozen activation table is assumed to cover observations, flow steps, and states induced by the compressed policy. These are not three unrelated failure cases: they are views of the same quantization--control feedback loop.

We propose \method, a full-context PTQ framework that audits policies rather than isolated tensors. \dpac supplies a sequence-level behavioral contract in physical control space. Local counterfactuals then propose exact-budget masks, but an abstaining full-policy audit accepts a mask only if complete-policy evidence passes task-level uncertainty and component-regression guards under both teacher- and candidate-induced observations. Finally, \dyrange removes the frozen activation lookup by conditioning channelwise A8 scales on the current deployment input. The operative principle is simple: local evidence proposes, the complete policy decides, and insufficient evidence preserves the initializer.

We evaluate on RoboCasa365~\cite{nasiriany2026robocasa365} using 50 seeds on each of 50 tasks. On GR00T N1.5, \method obtains 54.0\% task-macro success at 962,068,480 static bytes (2.22$\times$ compression), compared with 30.4\% for QuantVLA W4A8 and 55.1\% for FP16. The paired improvement over QuantVLA is significant after Holm correction ($p<10^{-4}$); the difference from FP16 is not significant ($p=0.2929$), which does not establish equivalence. The GR00T audit abstains and retains $M_0$. A paired intervention isolates the demonstrated deployment-context mechanism: the registered frozen A8 table obtains 0/500 successes, while input-conditioned A8 obtains 269/500 under the same weights. Under a matched four-flow-step protocol, the $\pi_{0.5}$ policy obtains 27.7\% success at 2.702$\times$ compression; a separate 4,000-episode LIBERO matrix provides cross-benchmark evidence for both models. The current evidence does not establish that \dpac is a superior rollout predictor, that every static quantizer fails, or that dynamic A8 improves latency or live memory.

Our contributions are threefold.
\begin{enumerate}[label=(\arabic*)]
    \item \textbf{Closed-loop PTQ formulation.} We identify the full-context gap: quantization changes actions, future observations, and hence the deployment distribution on which numerical fidelity is evaluated.
    \item \textbf{Abstaining full-policy audit.} We formulate mixed-precision selection as an exact-budget acceptance problem. Local interventions generate candidates; physical control sequences under teacher- and candidate-induced contexts determine whether a candidate is accepted or the procedure abstains.
    \item \textbf{Input-conditioned deployment and large-scale evidence.} We remove frozen A8 lookup tables through per-forward channelwise scaling and report 54.0\% success at 2.22$\times$ static compression on 2,500 GR00T episodes, plus a complete 4,000-episode LIBERO transfer matrix.
\end{enumerate}
