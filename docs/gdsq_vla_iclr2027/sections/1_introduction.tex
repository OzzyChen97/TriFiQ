\section{Introduction}
\label{sec:introduction}

Vision-language-action (VLA) models connect visual perception and language-conditioned reasoning to continuous robot control~\cite{brohan2023rt2,octo2024,kim2024openvla,black2024pi0,intelligence2025pi05,bjorck2025groot}. Their large multimodal backbones and iterative action generators make static storage and memory bandwidth important deployment constraints. Post-training quantization (PTQ) is attractive because it reduces numerical precision without retraining the policy~\cite{xiao2023smoothquant,lin2024duquant}.

Quantizing a VLA policy is not simply a layerwise reconstruction problem. An individually small action error can accumulate over a 16-step action chunk; rotation errors compose nonlinearly; discontinuities appear when consecutive replans are stitched together; and a small gripper timing shift can change task outcome. Moreover, the numerical effect of quantizing one layer depends on the precision of the rest of the policy. Local activation or reconstruction scores therefore need not predict the behavior of the complete mixed-precision network.

Activation range shift creates a second failure mode. Static A8 tables calibrated on a fixed buffer can become severely mismatched to the input distribution encountered by a generative controller. In our frozen attribution, the static-A8 reference has a normalized functional objective of 467, whereas dynamic A8 differs from the FP16 control by only 0.52. This gap motivates treating range adaptation as part of the deployment method, rather than as a calibration detail.

We propose \method, short for \emph{Dynamic-Range and Prefix-Accumulated Control-aware Quantization}. The central principle is to make precision decisions in the same context in which the policy will act. First, \dpac compares paired FP16 and quantized action sequences in physical coordinates. It combines local and prefix-accumulated errors with SE(3) pose, inter-replan stitch, and gripper-event terms, and adds CVaR tail risk. Second, Full-Context Precision Protection (\fcp) uses counterfactual layer flips and an exact byte-constrained candidate generator, but lets a whole-network cross-context score make the final decision. Third, the selected W4/FP16 plan is deployed using group-64 Hessian-aware weights and \dyrange, a deterministic per-forward, per-input-channel A8 rule. The final method has one global static mask and uses neither task-specific routing nor runtime correction.

The full-context search also exposes an important negative result. On GR00T, none of 116 one-layer flips improves the paired proxy around the prior 100-W4/16-FP16 mask, and all six whole-network proposals violate the minimax or component-safety rule. Thus \fcp validates that historical mask as a strict local optimum; it does not claim to discover a different mask. The final 3.2-point gain over GDSQ-VLA is obtained when the validated mask is run on the common Hessian-W4 + \dyrange substrate.

We evaluate on RoboCasa365~\cite{nasiriany2026robocasa365} using 50 paired seeds on each of 50 tasks. On GR00T N1.5, \method obtains 54.0\% task-macro success at 962,068,480 static component bytes (2.22$\times$ compression), compared with 50.8\% for the previous GDSQ-VLA runtime and 55.1\% for FP16. The improvement over GDSQ-VLA is significant under paired McNemar testing with Holm correction ($p=0.0036$); the difference from FP16 is not significant ($p=0.2929$). On $\pi_{0.5}$, budget pruning increases the number of W4 layers from 80 to 121 and yields 2.702$\times$ compression, but a 100-episode screen gives 29 versus 33 successes; we therefore make no success-rate superiority claim for that model.

Our contributions are threefold:
\begin{enumerate}[label=(\arabic*)]
    \item We introduce \dpac, a control-space quantization metric that captures prefix accumulation, composed SE(3) drift, inter-replan stitching, gripper-event timing, and tail risk over complete action sequences.
    \item We propose \method, a training-free full-context precision architecture that combines exact-budget W4/FP16 search, whole-network cross-context adjudication, Hessian-aware group-64 W4, and per-forward \dyrange without task routing or runtime correction.
    \item We provide an artifact-audited evaluation showing 54.0\% GR00T success: $+3.2$ points over GDSQ-VLA with Holm-adjusted $p=0.0036$, while remaining statistically tied with FP16; we also report the $\pi_{0.5}$ compression boundary without overstating its success evidence.
\end{enumerate}
