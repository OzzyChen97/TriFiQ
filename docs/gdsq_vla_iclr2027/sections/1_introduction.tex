\section{Introduction}
\label{sec:introduction}

Vision-language-action (VLA) models connect visual perception and language-conditioned reasoning to continuous robot control, allowing one policy to execute diverse instructions across scenes and embodiments~\cite{brohan2023rt1,driess2023palme,brohan2023rt2,octo2024,kim2024openvla}. Diffusion- and flow-based action heads improve continuous action generation~\cite{chi2023diffusionpolicy,liu2025rdt1b,black2024pi0,intelligence2025pi05,bjorck2025groot}, but large multimodal backbones and iterative denoising make deployment storage and memory bandwidth important constraints. Post-training quantization (PTQ) is appealing because it changes numerical precision without retraining the policy or redesigning its operator graph~\cite{xiao2023smoothquant,lin2024duquant}.

VLA quantization is difficult for two related reasons. First, numerical sensitivity is heterogeneous: an error in a language layer changes multimodal conditioning, whereas an error in an action layer can accumulate across denoising steps. Uniform low precision ignores this structure, while a fixed architecture-level protection rule cannot adapt to a new checkpoint. Second, a mixed-precision mask and its runtime correction are coupled. Attention-temperature modulation (ATM) and output-head balancing (OHB) may compensate residual quantization drift, but applying either mechanism indiscriminately can perturb an already stable model; applying both can double-correct the same propagated error. A deployable method must therefore decide both \emph{where} to quantize and \emph{whether} a calibrated correction is warranted.

Existing mixed-precision methods rank layers using local reconstruction error, activation magnitude, Hessian sensitivity, or task-specific proxies~\cite{hubara2021accurate,frantar2022gptq,wang2019hawq,dong2020hawqv2,chen2024qdit,zhao2024mixdq}. These signals are useful but incomplete for generative control. Centered kernel alignment (CKA) measures preservation of inter-sample geometry~\cite{raghu2017svcca,morcos2018pwcca,kornblith2019similarity}, yet is intentionally insensitive to isotropic scaling. Cauchy--Schwarz (CS) divergence measures distribution overlap~\cite{yin2026csaligner}, but does not say whether a shift changes the executed action. Neither local metric captures cancellation or amplification when many layers are quantized together, and neither determines whether a runtime correction should be admitted.

We address these challenges with \method, a training-free W4/FP16 allocation and correction-selection framework. For each candidate Linear layer, an isolated W4A8 intervention is compared with a paired full-precision attribution path. CKA and CS provide complementary representation evidence; paired action-trajectory sensitivity weights that evidence; and activation-RMS and saturation guards reject infeasible assignments. A byte-constrained allocator generates diverse masks, after which complete-configuration functional adjudication measures cross-layer action error. The result is a frozen mixed-precision plan rather than a per-task policy.

The final method then applies a \emph{calibration-gated runtime correction selector}. From model-level statistics of the frozen correction artifact, three preregistered thresholds either reject correction or admit the single dominant mechanism. Its output is restricted to the uncorrected baseline, ATM, or OHB; ATM+OHB is never an allowed final decision. The selector cannot inspect task identity, rollout success, or runtime feedback. The frozen v8 rule selects the baseline for GR00T N1.5 and OHB for $\pi_{0.5}$. On 256 frozen observations per model, each runtime path is bitwise identical to its corresponding static path, providing an explicit gate for any result reuse.

We evaluate on RoboCasa365~\cite{nasiriany2026robocasa365} with official horizons, four denoising steps, 16 executed actions per replan, and paired action noise. The completed GR00T selector result obtains 50.8\% task-macro success over 50 tasks at a theoretical 1.99$\times$ candidate-component compression, versus 55.1\% for FP16. Our contributions are threefold:
\begin{enumerate}[label=(\arabic*)]
    \item We formulate VLA precision allocation as action-weighted preservation of representation geometry and distribution overlap, with explicit stability guards and complete-mask functional adjudication under a frozen byte budget.
    \item We introduce a model-level calibration gate that selects at most one runtime correction mechanism without task metadata or outcome feedback, and we verify its selected execution paths by bitwise equivalence.
    \item We provide an auditable RoboCasa365 protocol in which manifests bind checkpoints, plans, code, environments, task/seed coverage, and paper cells; unsupported or incomplete results cannot populate the main table.
\end{enumerate}
