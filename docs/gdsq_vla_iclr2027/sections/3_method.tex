\section{Method}
\label{sec:method}

\paragraph{Overview.}
\method converts a frozen FP16 VLA into a single static W4/FP16 policy. Figure~\ref{fig:pipeline} summarizes three stages. First, paired teacher and candidate action chunks are compared with \dpac. Second, \fcp searches precision changes under an exact total-component byte budget and adjudicates complete candidates across task contexts. Third, the frozen plan is deployed with Hessian-aware group-64 W4 weights and dynamic per-forward A8 ranges. No success label, gradient, extra training data, task-dependent mask, runtime selector, or output correction is used.

\subsection{Prefix-Accumulated Control Divergence}
\label{sec:dpac}

Let $A^T=(a_1^T,\ldots,a_H^T)$ and $A^Q=(a_1^Q,\ldots,a_H^Q)$ be paired FP16-teacher and quantized action chunks generated from the same observation and initial action noise. We compare final physical actions after native inverse normalization, with $H=16$ and translation, rotation, gripper, and other deployed coordinates. A robust per-coordinate penalty
\begin{equation}
    \rho(z)=2\!\left(\sqrt{1+z^2}-1\right)
\end{equation}
limits domination by isolated outliers. Its scale $s$ is estimated once from the entire FP16 selection buffer using a MAD/RMS floor and is never re-estimated per sequence.

Local error alone ignores temporal accumulation. For action residual $e_h=a_h^Q-a_h^T$, the prefix term measures $\sum_{j=1}^{h}e_j/(s\sqrt{h})$ at every prefix. We additionally compose relative end-effector transforms in SE(3) for pose drift, compare the boundary between consecutive replans for stitch error, and measure both soft gripper state and open/close event timing. After normalizing the five components, a sequence score is
\begin{equation}
 d_{\mathrm{PAC}}=
 d_{\mathrm{local}}+d_{\mathrm{prefix}}+d_{\mathrm{pose}}+
 d_{\mathrm{stitch}}+d_{\mathrm{grip}}.
 \label{eq:dpac_sequence}
\end{equation}
The buffer-level divergence combines the sequence mean with $\operatorname{CVaR}_{0.9}$, exposing rare catastrophic deviations that a mean can hide. We also retain a complementary functional diagnostic
\begin{equation}
 \dfunc=d_{\mathrm{final}}+d_{\mathrm{kin}}+d_{\mathrm{grip}}
 +2\operatorname{CVaR}_{0.9}(d_{\mathrm{solver}}),
 \label{eq:dfunc}
\end{equation}
but the complete selection rule must be safe under both $\dpac$ and $\dfunc$.

\subsection{Full-Context Precision Protection}
\label{sec:fcp}

\paragraph{Context buffer.}
We collect FP16 on-policy observations from 12 tasks: four each from Atomic-Seen, Composite-Seen, and Composite-Unseen. Three seeds per task and four replans per sequence yield 36 sequences and 144 observations, stratified across early, middle, and late rollout windows. Task identifiers are used only to compute stratified statistics; the output remains one global mask.

\paragraph{Counterfactual search.}
Each target Linear layer has two states: native FP16 or signed-nibble group-64 W4. Starting from a complete mask, round one flips every W4 target to FP16 individually; round two flips every target state around the round-one winner. An exact sparse Pareto 0--1 dynamic program combines measured counterfactual benefits under
\begin{equation}
 C(M)=C_{\mathrm{fixed}}+\sum_i C_i(M_i)\le
 1.10\,C_{\mathrm{QuantVLA}},
 \label{eq:budget}
\end{equation}
where $C$ counts the same total static model components used in Table~\ref{tab:main_results}. Layer count is not a constraint. The dynamic program only proposes masks: non-additive interactions are decided after instantiating the complete network.

\paragraph{Whole-network adjudication.}
For every complete proposal, we recompute paired $\dpac$ and $\dfunc$ deltas on all contexts. The scalar objective is the worst normalized one-standard-error upper bound over both metrics and the all-task, Atomic, Composite-Seen, and Composite-Unseen clusters. A candidate must make this bound strictly negative and separately satisfy non-positive upper bounds for pose, stitch, and gripper components. Candidate-state rescoring checks the top three plans on observations induced by the candidate itself. These conservative rules prevent a favorable average from masking a harmful context or control component.

On GR00T, all 116 one-layer flips have non-positive benefit relative to the initialized 100-W4/16-FP16 mask, and all five additional full-network proposals are ineligible. The frozen winner is therefore the unchanged context baseline. This result supports local optimality in the tested one-layer-flip neighborhood; it is not evidence that \fcp discovered a new GR00T mask. For $\pi_{0.5}$, the budgeted plan flips the 41 lowest-benefit protected layers to W4, producing 121 W4 and 59 FP16 layers.

\subsection{Hessian-W4 and Dynamic-Range A8 Deployment}
\label{sec:deployment}

For each W4 layer, 256 calibration observations form FP16 input second-order statistics $X^\top X$. A GPTQ-style sequential error-feedback pass selects clipping and quantizes signed weights in groups of 64~\cite{frantar2022gptq}; row rotation is the identity and FP16 weights are not retained for W4 modules.

Static activation tables can fail under policy-induced range shift. \dyrange instead recomputes a scale for every target Linear, forward call, and input channel:
\begin{equation}
 s_c=\max\!\left(\frac{\max |x_{\ldots,c}|}{127},10^{-6}\right),
 \qquad q_c=\operatorname{clip}\!\left(\operatorname{round}(x_c/s_c),-127,127\right).
 \label{eq:dyrange}
\end{equation}
The rule is deterministic, uses the input dtype, and has no calibration table, flow-step selector, task selector, or candidate branch. The final policy applies the frozen W4/FP16 mask and Eq.~\ref{eq:dyrange} uniformly to every input; runtime correction is disabled.
