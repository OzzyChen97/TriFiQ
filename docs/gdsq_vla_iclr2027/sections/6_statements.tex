\subsection*{AI Use Statement}
\label{sec:ai-use-statement}

Generative AI tools were used to assist experiment planning, software
implementation and debugging, result aggregation and interpretation, drafting
and editing, reference and table formatting, and creation and post-processing
of the architecture figure. The authors reviewed the generated material,
tested AI-assisted code, reran the evidence and document gates, verified
numerical claims against frozen manifests and audited summaries, and checked
references against primary sources. No experimental result was synthesized by
a generative model. The authors take responsibility for the final content,
including all AI-assisted text, code, claims, and artifacts.

\subsection*{Reproducibility Statement}
\label{sec:reproducibility-statement}

Sections~\ref{sec:method} and~\ref{sec:experiments} specify the allocation,
selector, calibration, evaluation, and statistical protocols. The appendix
reports the frozen ratio analysis, controlled comparison, component ablations,
and correction diagnostics. The supplementary artifact includes versioned
manifests, configuration and code hashes, exact task/seed coverage, table
generators, and claim--evidence audits; every numerical paper cell is generated
from a frozen summary rather than entered by hand.
